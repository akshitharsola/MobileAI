# MobileAI — Project Report

## What This Project Is

MobileAI is an Android app that turns a smartphone (tested on Xiaomi 14 Ultra, 16GB RAM) into a
local LLM inference node. The Mac acts as orchestrator; the phone does the heavy computation.
Built on top of MLC-LLM (Apache 2.0), extended with a Telegram bot, embedded HTTP API server,
clipboard workflow, and background inference service.

---

## Architecture Overview

```
Phone (Xiaomi 14 Ultra)
├── MobileAI APK (277MB)
│   ├── Bundled model libraries (.so) for Qwen3-1.7B and Qwen3-4B
│   └── Downloads model weights from HuggingFace on first launch
│
├── ForegroundInferenceService (always running)
│   ├── MLCEngine (MLC-LLM JNI) — runs local inference
│   ├── ApiServer (Ktor on :8080) — HTTP API
│   └── TelegramPoller — long-polls Telegram Bot API
│
└── UI (Jetpack Compose)
    ├── HomeScreen — status + quick actions
    ├── ModelsScreen — select/load/download models
    ├── ChatScreen — local chat
    └── SettingsScreen — bot token, port, defaults

Mac (orchestrator)
└── OpenClaw / curl → POST http://phone-ip:8080/chat
```

## Important Files

### Android Source (`app/src/main/java/ai/mlc/mobileai/`)

| File | Purpose |
|------|---------|
| `MainActivity.kt` | Entry point. Starts ForegroundInferenceService, binds to it, auto-starts API server and Telegram bot on connect. Handles camera/gallery permissions. |
| `AppViewModel.kt` | Brain of the app. Wraps MLCEngine. Manages model download, load, unload lifecycle. Exposes `generateResponse()` for inference. Tracks RAM usage. Always deletes stale external mlc-app-config.json on launch so bundled assets are source of truth. |
| `ForegroundInferenceService.kt` | Android foreground service. Holds the MLCEngine reference (`chatState`). Provides `generateBlocking()` used by both ApiServer and TelegramPoller. Starts/stops ApiServer and TelegramPoller. |
| `ApiServer.kt` | Embedded Ktor HTTP server on port 8080. Endpoints: `GET /health`, `GET /models`, `POST /chat`, `POST /generate`. |
| `TelegramPoller.kt` | Long-polls Telegram Bot API (`getUpdates`). Passes prompts to inference. Handles `/start`, `/status`, `/model` commands. |
| `HomeScreen.kt` | Home UI. Shows model status, RAM, API server status, Telegram bot status. Quick action buttons: Models, Chat/Load Model, Start/Stop API, Start/Stop Bot. |
| `NavView.kt` | Navigation graph. Routes: `home`, `models`, `chat`, `settings`. |
| `ChatView.kt` | Local chat UI. Shows guard message if no model loaded. Supports text + image input. |
| `SettingsScreen.kt` | Telegram bot token, API port, default model selection. |
| `ClipboardMonitor.kt` | Monitors clipboard changes. Shows notification "Send to AI?" on text copy. |
| `ClipboardActionReceiver.kt` | Handles notification tap → sends clipboard to inference → puts response back. |
| `BootReceiver.kt` | Starts the service automatically on device boot. |
| `StartView.kt` | Splash/start screen shown during model loading. |

### Assets (`app/src/main/assets/`)

| File | Purpose |
|------|---------|
| `mlc-app-config.json` | Defines which models are bundled. Contains model IDs, library hashes, HuggingFace URLs, estimated VRAM. This is the source of truth — AppViewModel always deletes any external copy and uses this one. |

### Build Config

| File | Purpose |
|------|---------|
| `settings.gradle` | Includes `:app` and `:mlc4j`. Points mlc4j to `dist/lib/mlc4j` (the Android JNI library generated by `mlc_llm package`). |
| `app/build.gradle` | App dependencies: Compose, Ktor (HTTP server), OkHttp (Telegram polling), mlc4j project dep. |
| `mlc-package-config.json` | Input to `mlc_llm package`. Specifies both models, device=android, VRAM estimates, context window overrides. |
| `local.properties` | SDK path (not committed). |

### Generated (not committed, regenerated by build)

| Path | What It Is | Size |
|------|-----------|------|
| `dist/lib/mlc4j/` | mlc4j Android library — output of `mlc_llm package`. Contains `tvm4j_core.jar`, `libtvm4j_runtime_packed.so`, model `.so` files. Required for Gradle build. | ~807MB |
| `build/` (project root) | Intermediate cmake build artifacts from `mlc_llm package`. Safe to delete — regenerated. | ~1.3GB |
| `app/build/` | Gradle build outputs, APK. The APK itself is committed via Git LFS. | ~698MB |

### Patches (`patches/`)

| File | Purpose |
|------|---------|
| `mlc-llm.patch` | Patches to mlc-llm: fixes CMakeLists.txt (empty model_android.a placeholder), prepare_libs.py (logging API), tvm_runtime.h (tvm-ffi Error API, removed profiling.cc). Applied to `mlc-llm/` after cloning. |
| `tvm.patch` | Patch to tvm cmake/modules/Logging.cmake. Applied to `mlc-llm/3rdparty/tvm/`. |
| `build-config.cmake` | cmake config with USE_LLVM, USE_METAL for Mac build. |

## How the Build Works

### One-time Mac setup (to regenerate dist/)

```bash
# 1. Clone mlc-llm shallowly
git clone --depth=1 --recursive https://github.com/mlc-ai/mlc-llm.git
cd mlc-llm

# 2. Init all needed submodules
git submodule update --init --depth=1 3rdparty/tvm
git submodule update --init --depth=1 3rdparty/tokenizers-cpp
git submodule update --init --depth=1 3rdparty/xgrammar
git submodule update --init --depth=1 3rdparty/stb
cd 3rdparty/tvm/3rdparty/tvm-ffi
git submodule update --init --depth=1  # gets dlpack + libbacktrace
cd ../../../..
cd 3rdparty/tokenizers-cpp && git submodule update --init --depth=1 && cd ../..

# 3. Apply patches
git apply ../MobileAI/patches/mlc-llm.patch
cd 3rdparty/tvm && git apply ../../MobileAI/patches/tvm.patch && cd ../..

# 4. Build Mac dylibs (needed to run mlc_llm package)
mkdir build && cd build
cmake .. -DUSE_METAL=ON -DUSE_LLVM="/opt/homebrew/opt/llvm/bin/llvm-config"
cmake --build . --target tvm_runtime mlc_llm_module mlc_llm -j8
cd ..

# 5. Copy dylibs + install Python package
mkdir -p 3rdparty/tvm/3rdparty/tvm-ffi/build/lib
cp build/lib/libtvm_ffi.dylib 3rdparty/tvm/3rdparty/tvm-ffi/build/lib/
# Edit python/setup.py: add samefile check before shutil.copy (avoids SameFileError)
cd python && python setup.py develop && cd ..

# 6. Download OpenCL headers (needed for Android build)
mkdir -p /tmp/opencl_headers/CL
# Download cl.h, opencl.h, cl_platform.h, cl_version.h, cl_ext.h,
#          cl_gl.h, cl_gl_ext.h, cl_half.h, cl_egl.h, cl_icd.h from KhronosGroup/OpenCL-Headers

# 7. Run mlc_llm package (builds libtvm4j_runtime_packed.so + model libs)
cd /path/to/MobileAI
PATH="$HOME/.cargo/bin:$PATH" \
TVM_NDK_CC=~/Library/Android/sdk/ndk/26.3.11579264/toolchains/llvm/prebuilt/darwin-x86_64/bin/aarch64-linux-android26-clang \
ANDROID_NDK=~/Library/Android/sdk/ndk/26.3.11579264 \
MLC_LLM_SOURCE_DIR=/path/to/mlc-llm \
CPATH=/tmp/opencl_headers \
conda run -n Engineering python -m mlc_llm package
```

### Building the APK

```bash
cd /path/to/MobileAI
./gradlew assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk
```

## Key Design Decisions

- **mlc4j as Gradle subproject** (not AAR): The `dist/lib/mlc4j` directory contains full Kotlin/Java source — Gradle compiles it fresh. This avoids DEX-only AAR issues.
- **mlc-app-config.json always from assets**: AppViewModel deletes any external copy on launch. Prevents stale config surviving APK over-install.
- **ForegroundInferenceService**: Keeps inference running while app is backgrounded. API server and Telegram bot run in its coroutine scope so they survive home button press.
- **Git LFS for APK**: APK is 277MB — over GitHub's 100MB limit. Tracked via LFS.
